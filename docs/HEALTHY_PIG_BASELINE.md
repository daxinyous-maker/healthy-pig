# 健康小猪不可回退功能基线

状态：已确认功能基线。以下内容不得在后续修改中无意丢失。

## 品牌与布局

- 名称为“健康小猪”，主文案为“把宝宝养成健健康康的小猪”。
- 使用可爱、柔和的画风；小猪图标在图标框内居中，Emoji 尺寸清楚可见。
- 桌面网页使用左侧导航；手机网页和 APK 使用底部导航。
- 桌面弹窗居中；手机弹窗从底部展开，宽度正常，不缩在左下角。
- 栏目标题有清晰层级，“本周小结”“平均睡眠”等不能过小。

## 主导航与提醒

- “今天、趋势、计划、我的”都必须可点击并展示对应页面。
- 右上角提醒铃铛可点击；红点在查看提醒后消失。
- 提醒中的记录项和计划入口可继续操作。

## 记录与智能输入

- “记一笔”自动带入当前日期和时间，用户可以修改。
- 支持睡眠、饮食、运动、饮水以及用户启用的自定义习惯。
- 饮食由用户输入餐食和分量，系统估算热量；不要求用户直接输入热量。
- 支持语音转文字；不支持系统语音识别时提供清楚的降级提示。
- 支持输入或说一整段话，自然识别并拆分到睡眠、饮食、运动、饮水和自定义习惯。
- 智能识别结果在保存前可以修改项目、数值、记录时间和备注，也可以删除误识别项目。
- 智能识别必须理解“昨晚、昨天、午饭、晚饭、下午 3 点”等常用日期和时间表达，并写入对应记录时间。
- 智能输入弹窗内“说一说”“帮我识别”“确认添加”同宽、对齐；“说一说”高度不能过低。
- 历史记录必须有明确入口，并支持修改数值、项目、时间、备注以及删除单条记录。

## 趋势

- “平均睡眠、每日活动、平均饮水”可点击进入独立的每日趋势详情。
- 所有用户新增的习惯必须自动显示在趋势页。
- 点击任意项目可查看最近七天每天的数值和记录明细。
- 趋势支持最近 7 天、30 天和 3 个月切换，并使用曲线而非柱状图表达变化。
- 3 个月视图按每 3 天汇总为一个点，约显示 30 个点；不得通过拉宽页面容纳 90 个刻度。
- 趋势显示目标线和连续达标天数，允许给某天添加备注。
- “越少越好”的习惯必须明确说明曲线向下代表改善，并按上限目标判断；不能套用普通正向指标。

## 计划

- 计划可以新增、编辑、删除和勾选完成。
- 计划完成状态按日期保存，每天自动开始新的完成状态；计划支持每天、工作日、周末和仅一次四种重复方式。
- 底部按钮文案为“增加一项新计划”，不能变成记录活动。
- “我的”中的计划入口可以进入真正可调整的计划页面。

## 我的

- 不单独设置“个性资料”卡片。
- 点击头像即可更换 Emoji、拍照或选择照片；点击昵称即可直接输入修改。
- 栏目名称为“我的习惯”，不是“今日展示”。
- 睡眠、饮食、运动、饮水为基础项目。
- 吸烟、饮酒为可选习惯，可以选择展示或删除；删除不清除历史记录。
- 用户可以建立并删除任意自定义生活习惯。
- 自定义习惯支持完成状态、次数、时长、评分、文本和普通数值记录，并可设置“越多越好”或“越少越好”。
- 习惯显示顺序通过按住拖动手柄上下调整，不使用上下箭头；排序设置收纳在“设置”中。
- 睡眠、运动、饮水目标在当前页面直接修改，不得含糊地跳到计划页面。
- “我的”页面保持简洁；显示顺序、备份恢复和本地隐私说明收纳在可折叠的“设置”中。

## 本地数据与更新

- 所有个人健康数据仅保存在当前浏览器或手机应用中，不上传健康数据到云端。
- 网页更新要兼容已有本地数据。
- APK 覆盖安装要保留记录；卸载应用会清除手机本地数据，需要明确提醒用户。
- 网页端和手机端都支持导出本地备份文件与从备份恢复；恢复前必须确认，备份过程不得上传健康数据。

## 发布与交付

- 网页代码、APK 分开交付。
- 默认网站仅用户本人可访问；公开访问必须再次获得明确授权。
- 用户要求确认时，先交付本机预览，不得自行发布或打包。
